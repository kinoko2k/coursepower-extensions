# CoursePower Extensions

CoursePowerの各種機能を強化・改善する拡張機能です。
Google Chrome および Firefox の両ブラウザで動作します。

---

## 主な機能

### 1. 自動ログイン機能

CoursePowerのログイン画面で、設定したユーザIDとパスワードを自動入力し、自動的にログインを行います。

- **設定方法**: アドオンの設定から、ログインページのURL、ユーザID、パスワードを入力し、有効化します。
- **動作**: 対象のログインページを開くとカウントダウンが表示され、自動的にログイン処理が実行されます。

### 2. 教材の一括ダウンロード機能

講義の教材一覧ページにて、複数の教材ファイルを自動で順番に開き、ダウンロードを行います。

- **動作**: 対象ページを開くと、画面左下に「資料一括ダウンロード」パネルが表示されます。
- **機能**:
  - **すべて**: ページ内の全ての教材リンクを順次開いて、ダウンロードを行います。
  - **未参照のみ**: 未参照状態の教材リンクだけを自動で順次開いて、ダウンロードを行います。

> [!WARNING]
> **複数ファイルのダウンロード許可について**
> この機能を使用する際、Chromeのセキュリティ機能により「複数ファイルのダウンロード」または「ポップアップ」がブロックされることがあります。
> 初回実行時にブラウザのアドレスバー付近に警告（「複数ファイルのダウンロードをブロックしました」等）が表示された場合は、**「常に許可する」** を選択してください。許可しないと全てのファイルがダウンロードされません。

### 3. 授業ページの教材コンテンツを自動ですべて開く機能

授業の教材一覧ページを開いた際、授業ページの教材コンテンツを自動ですべて開くかどうかON/OFFできます。

- **設定方法**: アドオンの設定から、「授業ページの教材コンテンツを自動ですべて開く」にチェックを入れて有効化します。
- **動作**: 授業の教材ページを開いたときに自動的に「すべて開く」が実行されます。

## ブラウザへの拡張機能追加方法

### Google Chrome の場合

1. Google Chrome を起動します。
2. アドレスバーに以下の URL を入力してアクセスします。
   ```text
   chrome://extensions/
   ```
3. 画面右上の **「デベロッパー モード」** のスイッチをオンにします。
4. 画面左上に表示される **「パッケージ化されていない拡張機能を読み込む」** ボタンをクリックします。
5. ファイル選択ダイアログが開くので、このプロジェクトのフォルダ（`manifest.json` が入っているフォルダ）を選択して開きます。
6. 拡張機能が一覧に追加され、すぐにご利用いただけます。

---

### Firefox の場合

### 1. リリースページからダウンロードする（安定版）

1. リリースページを開く
   https://github.com/kinoko2k/coursepower-extensions/releases
2. 最新のリリースの中から、"coursepower-extensions.xpi" をダウンロードする
3. ダウンロードしたファイルを開いて、アドオンインストールを確認する

---

### 2. 一時的なアドオンとして追加する方法

ソースコードをそのまま読み込みます。

1. Firefox を起動します。
2. アドレスバーに以下の URL を入力してアクセスします。
   ```text
   about:debugging#/runtime/this-firefox
   ```
3. ページ内の **「一時的なアドオンを読み込む...」** ボタンをクリックします。
4. ファイル選択ダイアログが開くので、このプロジェクトのフォルダ内の `manifest.json` を選択して開きます。
5. アドオンが正しく読み込まれ、拡張機能一覧に追加されます。アドオンメニューからポップアップ画面や設定画面にアクセスできます。

> [!NOTE]
> 「一時的なアドオンを読み込む」方法で追加した場合、Firefox を終了・再起動すると読み込みが解除されます。継続して使用したい場合や次回再起動時にも利用したい場合は、再度同じ手順で `manifest.json` を読み込んでください。
